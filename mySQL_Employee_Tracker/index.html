Employee Tracker

A menu-driven terminal app for viewing and managing a company's departments, roles, and employees, with joined views that show each person's title, department, salary, and manager.

Run it locally

  1. Install Node.js and MySQL, then run npm install.
  2. Create and seed the database: mysql -u root -p < employee_DB.sql
  3. Copy .env.EXAMPLE to .env and add your MySQL user and password.
  4. Run npm start and choose from the menu.
